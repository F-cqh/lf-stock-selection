## 这份设计的核心主张

回测不准的根源**通常不在策略，而在地基**。所以设计里权重最高的不是功能清单，而是这几条：

- **原始价 + 复权因子分开存**，不存前复权价 —— 前复权会随除权重算历史，导致回测不可复现
- **信号日 ≠ 成交日**，硬性偏移一天，订单最早在下一个 bar 成交
- **T+1 / 涨跌停封死语义 / 停牌三件套**必须建模，且涨跌停价用整数分 + HALF_UP（不能用 Python 内置 `round`）
- **目标权重组合**，而非"挂单队列 + 有效期"
- **组合构建是独立一层** —— 同一选股逻辑换权重方案，收益差别可能比换因子还大
- **日频调仓在 A 股成本下几乎必死** —— 换手率是生死线（>40% 时净超额普遍转负）

以及一整节专门讲**静默错误**：跑得通、不报错、结果就是错的。这是回测引擎最危险的一类 bug。

```

│   └── web/               # FastAPI + Plotly.js
├── data/                  # Parquet 数据（不入库）
├── runs/                  # 回测结果（不入库）
└── tests/
```

## 声明

个人研究项目，**不构成任何投资建议**。回测表现不代表未来收益，历史数据可能存在幸存者偏差、前视偏差等问题 —— 这份设计文档里有相当篇幅就是在讲如何避免自欺。
